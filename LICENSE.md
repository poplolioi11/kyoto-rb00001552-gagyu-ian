# 權利與授權 / Rights and licensing

原文署文化乙亥（1815）。京都大學附屬圖書館說明其公開數位化的原件著作權保護期已屆滿，該件數位影像標示自由再利用。封存資料附逐欄轉錄、訂正和館方原圖定位。 The original text is in the public domain. Kyoto University’s reuse guide covers the library’s digitization. The dataset supplies text, documentation and references to the selected scans.
